UPC databases

App updates

The app checks for a new version every time it opens and installs it automatically, with a progress bar on the start screen. Your pricebook, edits, tag queue, barcode links and settings are kept.
Updates come from the GitHub repository hpneptune/shelf-tag-studio and from the site the app was installed from. Whichever has the newer version wins, and the app never goes back to an older one. To use a different address on this device, paste the web folder that holds version.json (a GitHub repository or folder, GitHub Pages, or another site that allows downloads from other sites) and tap Save address. Leave the box blank and save to go back to the built-in address.
